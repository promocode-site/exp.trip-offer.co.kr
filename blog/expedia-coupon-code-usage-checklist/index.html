익스피디아 할인코드, 어디에 입력하나요

익스피디아에서 호텔이나 항공권을 예약할 때는 결제 화면 직전 단계에 프로모션 코드를 입력하는 칸이 따로 있습니다. 숙소나 상품을 고르고 결제 정보를 입력하는 페이지로 넘어가면 "프로모션 코드" 혹은 "쿠폰 코드"라고 적힌 입력란이 보이는데, 여기에 코드를 넣고 적용 버튼을 누르면 할인된 금액이 바로 반영됩니다.

코드를 입력해도 화면에 변화가 없다면 결제 금액이 갱신됐는지 먼저 확인해야 합니다. 간혹 적용 버튼을 눌렀는데도 새로고침이 되지 않아 할인이 반영되지 않은 것처럼 보이는 경우가 있기 때문입니다. 최신 익스피디아 할인코드 목록은 계속 바뀌기 때문에, 예약 직전에 한 번 더 확인하는 습관을 들이는 것이 좋습니다.

사진: Campaign Creators / Unsplash

카드사별 할인코드와 상황별 할인코드

익스피디아는 제휴 카드사에 따라 각각 다른 할인코드를 운영하고 있습니다. KB카드는 KBCARD9, 하나카드는 HANA9, 신한카드는 SHINHAN9, 현대카드는 HYUNDAI9, 우리카드는 WOORI9 코드로 각각 9% 할인이 적용되고, BC카드는 BCCARD8 코드로 9% 할인을 받을 수 있습니다. 이 카드사별 코드들은 모두 예약 기간이 2026년 12월 31일까지이고, 투숙 기간은 2027년 3월 31일까지로 정해져 있으니 기간을 넘기지 않도록 확인해야 합니다.

카드사 코드 외에도 마스터카드 이용자를 위한 MASTERKR8(8% 할인, 예약 기간 2027년 1월 31일·투숙 기간 2027년 6월 30일)과 비자카드용 VISAYRO(8% 할인), 아멕스카드용 AMEXKR8(8% 할인), NH카드용 NHCARD8(8% 할인)도 있습니다. 카드사 조건에 해당하지 않는다면 일반 코드인 EXP7(7% 할인)이나 LOCA7, SSTRAVEL07(각 7% 할인)을 사용할 수 있고, EXP5(5% 할인)는 예약 기간이 9월 30일까지라 며칠 남지 않았으니 서두르는 것이 좋습니다.

익스피디아 할인코드 받기 페이지에서는 현재 쓸 수 있는 코드를 한 번에 확인할 수 있어서, 카드사 코드와 일반 코드 중 더 유리한 쪽을 비교해 보는 데 도움이 됩니다.

예약 전에 확인해야 할 것들

할인코드를 적용하기 전에 가장 먼저 볼 것은 취소 및 환불 규정입니다. 같은 숙소라도 요금제에 따라 무료 취소가 가능한 상품과 환불이 불가능한 특가 상품이 함께 노출되는 경우가 많은데, 할인코드가 적용된 금액만 보고 결제했다가 일정이 바뀌었을 때 곤란해질 수 있습니다. 예약 확정 전에 취소 기한과 조건을 캡처하거나 메모해 두는 것을 권합니다.

두 번째로 확인할 것은 통화 단위와 표시 가격입니다. 해외 숙소를 예약할 때 원화로 표시되는 가격과 실제 카드 결제 시 청구되는 현지 통화 환산 가격이 다를 수 있으므로, 결제 수단의 해외 결제 수수료도 함께 고려하는 것이 좋습니다. 또한 할인코드마다 적용 가능한 상품 범위와 최소 결제 금액 조건이 다를 수 있으니, 결제 전 안내 문구를 한 번 더 읽어보는 습관이 실수를 줄여줍니다.

마지막으로 코드의 예약 기간과 투숙 기간을 헷갈리지 않아야 합니다. 예약 기간은 코드를 사용해 결제를 완료해야 하는 기한이고, 투숙 기간은 실제로 숙소에 머무를 수 있는 날짜 범위를 뜻합니다. 두 기간이 다른 코드가 많으므로 일정을 잡을 때 두 조건을 모두 만족하는지 확인해야 합니다.

코드 적용이 안 될 때 확인할 것

코드를 입력했는데 오류가 뜨거나 할인이 반영되지 않는다면 몇 가지를 순서대로 점검해 보면 좋습니다. 우선 코드는 대소문자를 구분하지 않는 경우가 많지만, 띄어쓰기나 오타가 섞이면 인식되지 않으므로 복사해서 붙여넣는 방식을 추천합니다. 그다음으로는 코드의 예약 기간이 지나지 않았는지, 선택한 상품이 코드 적용 대상에 포함되는지를 확인해야 합니다.

특가로 표시된 일부 상품은 이미 할인된 가격이라 추가 코드 적용이 제한되기도 합니다. 이럴 때는 코드를 적용하지 않은 일반 상품과 가격을 비교해 보고 어느 쪽이 실제로 더 저렴한지 따져보는 것이 안전합니다. 브라우저 캐시나 로그인 상태 문제로 오류가 계속된다면 새로고침 후 다시 시도하거나 다른 브라우저에서 진행해 보는 것도 방법입니다.

할인코드 적용이 잘 안 될 때는 익스피디아 특가 확인하기에서 코드 조건을 다시 확인하고, 조건에 맞는 다른 코드로 바꿔서 시도해 보는 것도 좋은 방법입니다.

자주 묻는 질문

Q. 할인코드는 한 번에 여러 개를 같이 쓸 수 있나요? A. 결제 화면의 프로모션 코드 입력란은 보통 하나만 적용되도록 되어 있어서, 여러 코드를 동시에 넣기보다는 조건에 맞는 코드 중 할인율이 더 높은 하나를 선택해 사용하는 것이 일반적입니다.

Q. 카드사 할인코드는 아무 카드로나 써도 되나요? A. KBCARD9, HANA9, SHINHAN9, HYUNDAI9, WOORI9, BCCARD8처럼 카드사 이름이 붙은 코드는 해당 카드사의 카드로 결제할 때 적용되는 경우가 많으므로, 실제 결제에 쓸 카드와 코드가 맞는지 먼저 확인하는 것이 좋습니다.

Q. 할인코드 유효기간이 지나면 어떻게 하나요? A. 코드마다 예약 기간과 투숙 기간이 다르게 정해져 있어서, 기간이 지난 코드는 사용할 수 없습니다. 익스피디아 할인코드 메인 페이지에서 현재 유효한 코드를 다시 확인한 뒤 예약을 진행하는 것을 권합니다.
