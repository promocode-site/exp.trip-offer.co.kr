카드사 코드가 이렇게 나뉘는 이유

익스피디아는 국내 카드사와 개별 제휴를 맺어 할인코드를 운영하는 경우가 많습니다. 그래서 같은 9% 할인이라도 코드 이름이 카드사마다 다르고, 결제할 때 반드시 해당 카드로 결제해야 정상 적용됩니다. 예를 들어 KBCARD9은 KB국민카드로 결제할 때만 할인이 반영되고, 다른 카드로 결제하면 코드 입력란에서 오류가 나거나 할인이 빠질 수 있습니다.

카드사별 9% 코드 6개 중 자신이 쓰는 카드가 없다면 무리하게 다른 카드사 코드를 적용하려 하지 마세요. 대신 카드사 조건이 없는 EXP7(7% 할인)처럼 조건이 더 넓은 코드를 살펴보는 방법도 있습니다. 다만 할인율이 9%보다 낮아지는 점은 감안해야 합니다.

예약 전에 꼭 확인할 것

카드사 코드는 할인율이 높은 만큼 조건도 촘촘한 편입니다. 예약하기 전에 아래 세 가지는 꼭 짚고 넘어가세요.

  • 결제 카드: 코드에 표시된 카드사의 카드로 결제해야 합니다.
  • 예약·투숙 기간: KB국민·하나·신한·현대카드 코드는 2026년 12월 31일까지 예약, 2027년 3월 31일까지 투숙해야 적용됩니다.
  • 코드 입력 위치: 결제 마지막 단계에서 프로모션 코드란에 정확히 입력해야 하며, 오탈자가 있으면 할인이 반영되지 않습니다.

코드 입력 순서나 화면별로 주의할 점이 더 궁금하다면 익스피디아 쿠폰 코드 사용법과 예약 전 확인사항 글에서 단계별로 정리해 두었으니 참고해 보세요.

카드가 다를 때 대안 찾는 법

가지고 있는 카드가 위 6개 카드사에 해당하지 않는다면 다른 카드사 조건의 코드를 살펴보는 것도 방법입니다. 마스터카드 이용자는 MASTERKR8(8% 할인, 예약 기간 2027년 1월 31일까지·투숙 기간 2027년 6월 30일까지)을, 비자카드 이용자는 VISAYRO(8% 할인)를, 아멕스카드 이용자는 AMEXKR8(8% 할인)을, NH농협카드 이용자는 NHCARD8(8% 할인)을 확인해 보세요. 9%보다 할인율이 1%p 낮지만 조건이 맞는 카드로 결제하면 무리 없이 적용됩니다.

카드사 조건과 별개로 최신 코드를 한 번에 비교하고 싶다면 익스피디아 할인코드 받기 페이지에서 현재 활성화된 코드 목록을 확인할 수 있습니다. 예약 시점에 따라 코드 조건이 바뀔 수 있으니 결제 직전에 다시 확인하는 습관을 들이는 것이 좋습니다.

숙소 유형이나 결제 금액에 따라 할인 적용 범위가 달라질 수 있으므로, 지금 적용 가능한 코드 확인하기에서 조건을 함께 살펴보고 예약을 진행하시길 권합니다.

자주 묻는 질문

Q. 카드사 9% 코드를 다른 카드로 결제해도 되나요? A. 안 됩니다. 코드마다 지정된 카드사의 카드로 결제해야 할인이 정상 반영됩니다. 다른 카드로 결제하면 할인이 적용되지 않거나 코드 자체가 거부될 수 있습니다.

Q. KBCARD9, HANA9, SHINHAN9, HYUNDAI9 중 어느 코드가 더 유리한가요? A. 할인율과 예약·투숙 기간이 모두 동일해서, 소지한 카드사 코드를 고르면 됩니다. 특별히 더 유리한 코드는 없습니다.

Q. 우리카드나 BC카드 코드는 기간 제한이 없나요? A. 현재 공개된 정보에는 별도 기간이 표시되어 있지 않지만, 조건은 변동될 수 있으니 예약 전 화면에서 다시 확인하는 것이 안전합니다.
